# 🔐 Professional Password Generator

A sleek and secure password generator built with **Vanilla JavaScript**, **HTML5**, and **CSS3**. This tool allows users to create strong, random passwords based on custom preferences.

## ✨ Features
* **Custom Length:** Choose password length between 4 and 32 characters.
* **Security Options:** Include Uppercase, Lowercase, Numbers, and Symbols.
* **One-Click Copy:** Easily copy the generated password to your clipboard.
* **Input Validation:** Prevents copying empty strings or errors.
* **Responsive Design:** Works perfectly on desktops and mobile devices.

## 🚀 Technologies Used
* HTML5
* CSS3 (Flexbox & Linear Gradients)
* JavaScript (DOM Manipulation & Clipboard API)
